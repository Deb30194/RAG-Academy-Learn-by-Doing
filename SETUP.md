# RAG Academy – Learn by Doing

RAG Academy is an interactive learning platform designed to make Retrieval-Augmented Generation (RAG) easier to understand through simple explanations, practical coding exercises and hands-on experiments.

## Features

- Introduction to RAG
- Interactive RAG pipeline walkthrough
- Chunking playground
- Embeddings learning module
- Search and retrieval experiments
- Mini document-based retrieval assistant
- RAG debugging exercises
- Final challenge and quiz

## Getting Started

### 1. Install dependencies

pip install -r requirements.txt

### 2. Run the application

python -m streamlit run app.py

### 3. Open the application

Visit http://localhost:8501 in your browser.

## Technology Stack

- Python
- Streamlit
- PyPDF

Retrieval-Augmented Generation (RAG) Pipeline Development.
